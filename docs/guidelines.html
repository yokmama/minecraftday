運営ガイドライン

マイクラデイを安全に開催するための指針

ホーム > ガイドライン
ガイドラインについて
このガイドラインは、マイクラデイを安全かつ効果的に開催するための指針です。 協会会員はこのガイドラインに従ってイベントを運営してください。

1. 基本方針

1.1 安全第一

参加者（特に子供たち）の安全を最優先とします。 物理的な安全だけでなく、心理的な安全も確保してください。

1.2 楽しさを第一に

マイクラデイは子供たちが楽しむためのイベントです。 教育的な要素よりも、まず「楽しい」と思える体験を提供することを大切にしてください。

1.3 参加者同士の尊重

参加者全員がお互いを尊重し、いじめや暴言のない環境をつくります。 経験の差に関わらず、誰もが楽しめる雰囲気づくりを心がけてください。

1.4 著作権の遵守

Minecraftの知的財産権を尊重し、Mojang Studios / Microsoft Corporationの ブランドガイドラインに従った活動を行います。

2. イベント準備

2.1 会場の選定

  • 十分なスペースがあること（1人あたり2㎡以上推奨）
  • 電源が十分に確保できること
  • 空調設備があること
  • トイレ・手洗い場があること
  • 緊急時の避難経路が確保されていること

2.2 必要な機材

機材 目的 備考
サーバーPC マインクラフトサーバーの稼働 推奨スペックあり
クライアントPC 参加者のプレイ用 参加人数分
ネットワーク機器 ローカルネットワーク構築 ルーター、LANケーブル等
電源タップ 電源供給 十分な容量のもの
マウス・キーボード 操作用 参加人数分

2.3 ソフトウェアの準備

Minecraftが動作する環境を用意してください。 使用するエディション（Java版・Bedrock Edition）やサーバー構成は、イベントの内容に応じて運営側で決定します。

重要：ライセンスについて
参加者は各自Minecraftの正規ライセンスを所有している必要があります。

3. 運営体制

3.1 スタッフ配置

  • イベント責任者：1名（必須）
  • 技術担当：1名以上（サーバー・ネットワーク管理）
  • 見守りスタッフ：参加者5名につき1名以上

3.2 参加者の管理

  • 事前申込制を推奨
  • 参加者名簿の作成・管理
  • 保護者の連絡先の把握
  • アレルギー等の健康情報の確認

4. 当日の運営

4.1 受付

  • 参加者の本人確認
  • 保護者への連絡事項の伝達
  • ルールの説明と同意確認

4.2 イベント中のルール

  • 他の参加者への暴言・いじめの禁止
  • 機材の丁寧な取り扱い
  • 適度な休憩の取得（1時間に1回推奨）
  • 飲食は指定された場所でのみ

4.3 緊急時の対応

  • 緊急連絡先リストの準備
  • 応急処置キットの用意
  • 避難経路の事前確認と参加者への周知

5. 著作権・知的財産権

5.1 Minecraftの商標について

「Minecraft」はMojang Studiosの商標です。 イベント名や広報物で使用する際は、以下の点に注意してください。

  • Mojang / Microsoftの公式イベントではないことを明示する
  • 商標を不適切に使用しない
  • 公式と誤解されるような表現を避ける

5.2 推奨される免責文言

「このイベントはMojang Studios、Microsoft Corporationとは一切関係がありません。 MinecraftはMojang Studiosの商標です。」

5.3 コンテンツの利用

  • 公式のスクリーンショットやアート等を使用する場合は、Mojangのガイドラインに従う
  • 非公式のMod・プラグインを使用する場合は、各作者のライセンスを確認する
  • 参加者が作成したコンテンツの権利は、原則として参加者に帰属する

6. 個人情報の取り扱い

  • 収集した個人情報は、イベント運営の目的のみに使用する
  • 第三者への提供は行わない（法令に基づく場合を除く）
  • イベント終了後は適切に破棄する
  • 写真・動画の撮影は事前に許可を得る
